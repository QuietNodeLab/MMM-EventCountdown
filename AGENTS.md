# Package development

This is a standalone MagicMirror module. Keep all styles scoped to
.MMM-EventCountdown and use synthetic data in tests and screenshots.
Do not include personal configuration, account names, source-machine paths,
private history, credentials, or personal names in public artifacts.
Run npm test with Node 24. Runtime dependencies come from MagicMirror;
no npm install is needed for users. No external APIs are required.
Publishing, remote repository creation, announcements and deployment require
an explicit user request. Never access or change a production device.
