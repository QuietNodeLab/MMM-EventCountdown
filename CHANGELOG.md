# Changelog

## 0.1.0 — prepared for publication

- Standalone MagicMirror event and holiday countdown cards.
- Local JSON data, inclusive multi-day ranges, and yearly holiday rollover.
- Independent data files for multiple module instances.
- Configurable timezone, heading, entry limit, refresh interval, and emoji display.
- Preview mode using synthetic dates without a data file.
- Scoped, responsive styling and synthetic screenshots.
- MIT license and eleven offline regression tests.

No external API, API key, companion module, or extra runtime npm package is required.

Validated locally with MagicMirror 2.38.0, Node 24, and Chromium. Docker, Electron
startup, physical displays, and prolonged unattended operation remain unverified.
